# Система управления студентами

## Описание проекта

Система управления студентами — это консольное приложение, разработанное на языке C#. Оно позволяет пользователям управлять данными о студентах, включая добавление, удаление, сортировку и вывод списка студентов. Проект предназначен для обучения основам программирования, работы с массивами и обработки пользовательского ввода.

## Функциональность

Приложение предоставляет следующие функции:

- **Добавление студента**: Пользователь может ввести данные о новом студенте, включая имя, возраст, оценку и специальность.
- **Удаление студента**: Пользователь может удалить студента по его ID.
- **Сортировка студентов**: Студенты могут быть отсортированы по имени, возрасту или оценкам.
- **Вывод списка студентов**: Пользователь может просмотреть список всех добавленных студентов.

## Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш_пользователь/StudentManagementSystem.git
   ```
Откройте проект в Visual Studio:

Запустите Visual Studio и откройте проект, выбрав файл .sln.
Запустите приложение:

Нажмите F5 или выберите Запустить в меню, чтобы запустить консольное приложение.
Использование
После запуска приложения вы увидите главное меню с доступными действиями. Введите номер действия и следуйте инструкциям на экране. Пример меню:

+---------------------------------------+
|          Меню управления              |
+---------------------------------------+
| 1. ➕ Добавление студента             |
| 2. ➖ Удаление студента               |
| 3. 🔄 Сортировка студентов            |
| 4. 📋 Вывести список студентов        |
| 0. ❌ Выход                           |
+---------------------------------------+
Пример использования
Выберите пункт 1 для добавления студента.
Введите имя, возраст, оценку и специальность студента.
Выберите пункт 4 для вывода списка студентов и проверьте, что новый студент добавлен.
